# Sources Catalog

Catalog of reusable reference material for this scope. Every file in `files/` must have an entry here.

**Protocol:** read `instance.yaml` in this directory, then `users/<principal>/types/source/README.md`

---

## Files

### Example — W-2 2025

- **id:** source.w2-minerva-2025
- **media_type:** pdf
- **source_type:** internal_file
- **path_or_url:** `files/2025/w2-minerva.pdf`
- **summary:** Minerva University W-2, Sep 25–Dec 31 2025
- **sensitivity:** high
- **tags:** tax, income, 2025
- **added:** YYYY-MM-DD
